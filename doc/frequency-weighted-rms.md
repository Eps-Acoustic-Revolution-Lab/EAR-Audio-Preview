# Frequency-weighted RMS estimates

The selector above the single-file level meters offers **RMS Z**, **RMS A**, **RMS B**, and **RMS C**. Z remains the default and retains the existing rectangular-window RMS calculation. The selection lasts for the lifetime of the current meter panel. Weighted readouts use RA/RB/RC labels, in dBFS, and the bright RMS bar follows that estimate. Peak bars, clip LEDs, peak hold, hearing-protection trigger, playback and exports remain unweighted.

A/B/C apply the conventional analogue frequency-response magnitudes, normalized to unity at 1 kHz. A and C use the pole frequencies 20.598997, 107.65265, 737.86223 and 12194.217 Hz as applicable. B adds the legacy 158.5 Hz pole to C. Sources: [A/C filter derivation](https://pmc.ncbi.nlm.nih.gov/articles/PMC4331191/) and [ANSI S1.4-1983, Appendix C](https://law.resource.org/pub/us/cfr/ibr/002/ansi.s1.4.1983.pdf).

The estimator removes each tap's DC mean, applies a periodic Hann window and sums weighted FFT power. With an unnormalized DFT X, sample count N, window w and magnitude response H, mean square is `sum(c[k] * |X[k]|² * |H[k]|²) / (N * sum(w²))`, where c is 2 for interior positive-frequency bins and 1 for DC/Nyquist. This window-power normalization preserves stationary signal power; it does not apply the coherent-gain normalization used for amplitude spectra. Each displayed L/R or M/S column is measured after the existing monitoring matrix. The AudioContext sample rate determines bin frequencies, including when it differs from the source file's rate.

This is a short-window spectral estimate, not a continuous filter or a certified sound-level meter. Taps contain at most 2048 samples (42.7 ms and 23.4 Hz bin spacing at 48 kHz); smaller analyser windows and higher sample rates further reduce low-frequency resolution. Demeaning and spectral leakage can bias low-frequency or transient signals. Repeated/overlapping snapshots are independent, so there is no fictitious filter history. Existing display attack/release smoothing applies; no IEC Fast/Slow time weighting or calibrated SPL measurement is implied. These values are not dBA/dBC SPL or LUFS.

Tests cover reference gains, 1 kHz normalization, tone power across four sample rates, silence, independent channels, repeated snapshots and preservation of unweighted peaks. Native visual acceptance and standards certification are separate from those checks.
