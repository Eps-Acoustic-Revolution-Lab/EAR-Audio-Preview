# EAR 对齐 DSP 研发实验

> 研究快照：下文保留实验阶段说明，不描述当前产品状态。v0.6.0 已集成 Align；这里的拟合残差与产品中的残差测量接口用途不同。公开副本仅调整本机素材路径；原始与当前哈希见 source.json。

仅在独立工作区运行的 DSP 原型，不接入 EAR 界面、播放链或导出链。研发分支：`research/alignment-dsp-lab-20261016`。基于提交 `06705d4807e121e60737a080daa0a2d6bd2827dd` 创建，没有复制主工作区正在修改的代码。

## 交付内容

- `estimateAlignment(aChannels, bChannels, sampleRate)`：整数采样点固定延迟估计，返回偏移、极性、相关度及接受／拒绝原因。
- `compareResidual(aChannels, bChannels, sampleRate, offsetSamples)`：对有效重叠区拟合一个保持声道比例的增益，测量立体声残差 RMS、峰值和相消深度。支持负增益，但是否补偿极性应由未来的产品交互明确决定。
- 固定竞品源码、官方测试、开发／留出测试、真实音频变体、交替顺序计时和机器校验门禁。

这里的增益拟合服务于相减测试，不是 LUFS 监听音量匹配。

## 五轮对抗审查后的结果（2026-10-16）

后续的[四因素消融实验（2026-10-17）](ablation/README.md)已完成：在318个固定案例及16组合中，声道策略和极性支持分别解释26个正例差距；多候选的已测收益为拒绝周期多解；短窗口显著减少长输入耗时。部分白化未增加本语料的成功数，其速度影响取决于提前退出。该实验没有改动算子默认配置。

按 cross-gan-review 完成五轮独立生成器／判别器审查。只改实验算子、追加回归测试及实验文档；原有测试、语料、竞品源码和评测门槛的 SHA-256 均未改变。

- 相对本次优化前的算子，两轮同进程交替计时中，30 秒四份真实音频快约 **1.34–1.38 倍**，耗时减少约 **25–27%**；3 秒快约 **1.06–1.08 倍**。主要收益来自完整 PCM 有限值检查的八样本循环展开，所有样本仍逐一检查。
- 相对固定 audioscope v1.1.8，两轮完整复测：30 秒快约 **2.80–2.87 倍**，3 秒快约 **1.33–1.38 倍**。这是本机、当前 Node.js 与固定四份素材的结果，不代表所有输入或宿主环境。
- 原有留出集仍为 **72/72**，真实音频变体 **16/16**，负例无误接受；追加确认 **58/58** 及六组增益残差检查通过。每轮另核对 **250 个固定案例的对齐与残差返回值逐字节不变**。这些是已使用过的固定回归语料，不是新盲测。
- 修复四类误拒绝：稀疏样本被能量探针漏掉、稀疏音频精修窗口落在静音区、尾部有效音频未被窗口覆盖、极小非零背景阻止尾部回退。新增五个测试组，包含大量非法值位置检查；默认 `npm test` 运行原六组、新五组及竞品原八组测试。
- 合并 FFT 和融合 FIR 的候选均未保留：前者端到端收益落在噪声范围；后者在实际算子中两轮变慢。没有用微基准或临时内存实现的收益替代实际实现证据。

## 首次交付实测结果（优化前，保留历史口径）

两轮独立计时，每轮对四份本地录音分别测试 3 秒和 30 秒，预热 2 次、正式交替测量 7 次。各项均检查偏移正确性。

- **30 秒音频：约快 1.71–1.88 倍，耗时减少约 41–47%。** 竞品中位耗时约 29–31 ms；原型约 16–17 ms。
- **3 秒音频：基本持平。** 两轮的速度比为 0.91–1.06，未证明短音频上的稳定提速。
- **合成留出集：72/72 个正例通过，竞品 56/72。** 普通同极性、非 Side-only 的 56 个案例双方全部通过；差异来自整体极性反转和左右声道相消这两组边界条件。所有候选结果误差不超过 1 个采样点。
- **真实素材变体：16/16 通过，竞品 12/16。** 两者在 12 个普通正例上全部通过，另外 4 个为极性反转。
- **拒绝策略：32 个合成负例全部拒绝。** 包括独立噪声成分但共享调性结构的信号、静音、常量及周期多解信号。竞品没有拒绝状态，其中 13 个返回非零偏移；这不是同一个“误报率”接口，不能直接说它 32 个全部对齐错误。
- **追加确认：58/58 通过。** 新种子的 52 个案例与 6 组不同真实录音配对。另有 6 个立体声／Side-only、正负增益案例，偏移准确、增益误差小于 1e-5、残差相消深度超过 100 dB。
- 当时原型单元测试 **6/6**；竞品原有测试 **8/8**，只重定向导入路径，没有修改断言。

这组历史数据保存在 [.cross-gan/baseline/](https://github.com/Eps-Acoustic-Revolution-Lab/EAR-Audio-Preview/tree/4f0a2361c10f89a881d52d118b43761cbd1840a7/doc/research/audio-alignment/.cross-gan/baseline/)。`results/` 现为五轮审查后重新生成的当前结果。

## DSP 设计

### 1. 避免声道相消

不把 L/R 直接平均。先在对应声道对中选择较有信息量的一组进行时间差估计，最后将同一偏移用于所有声道。这样可以保留 Side-only 信号；同时不会独立移动左右声道而改变声像。

这是声道选择方案，不是多声道联合最大似然估计。某些声道包含强干扰而另一些更易对齐的情形仍需要额外验证。

### 2. 限制粗搜索规模

在前 60 秒中寻找有能量的区域，截取与搜索半径相关的短窗口；默认 ±2 秒搜索时窗口为 4.5 秒。通过 Blackman 窗 sinc FIR 低通后，降采样至约 2 kHz。滤波器截止频率为输出 Nyquist 的 80%，半径为 4 倍抽取因子。

与竞品最多使用 60 秒的粗搜索相比，FFT 和滤波工作量明显减少。代价是代表性依赖于局部窗口，不能保证覆盖整段录音中的所有变化。

### 3. 部分白化互相关与极性支持

计算 `IFFT(conj(A) * B / max(|A||B|, floor)^0.5)`。它处于普通互相关与完整 PHAT 之间，减弱强谱峰对粗定位的支配，同时给低能量频点设置下限。

按相关绝对值选择最多三个候选峰，因此可以找到极性反转的副本；再在原采样率下逐样本精修。FFT 为独立实现的 radix-2 算子，使用原位缓冲区和无数组分配的蝶形循环。

### 4. 明确拒绝不可靠结果

精修使用去均值归一化互相关。当前实验阈值为 `abs(rho) >= 0.75`；若不同候选的相关绝对值相差小于约 1.5%，拒绝自动执行。近乎完全相关且粗峰显著唯一时，可以提前结束其他候选精修。

`confidence` 是相关系数绝对值，不是成功概率。阈值在开发集上调整一次，保留了调整前失败结果；留出集只用于确认。

### 5. 立体声增益与残差

在实际重叠区、全部声道上累计点积与能量：`g = sum(A*B) / sum(B*B)`，然后测量 `A - g*B`。不让非重叠补零尾部影响增益拟合，也不因声道平均相消而丢失增益信息。

这与竞品的单声道拟合、正增益约束和补零统计口径不同，因此残差改善应结合具体定义解释；没有据此宣称所有处理结果都会更好。

## 复现

需要 Node.js 24+，不需要安装 npm 依赖。真实音频准备脚本使用 macOS 自带 `afconvert`；音频原件和解码 PCM 不进入 Git。

```sh
cd dsp-lab
node prepare-audio.mjs /path/to/audio-directory
npm test
npm run evaluate
npm run bench
npm run verify
```

`timing-pass-1.json` 是保留的第一轮计时，`timing.json` 是最近一次计时。`verify.mjs` 检查当前算子和竞品源码的 SHA-256、准确率、拒绝策略、计时正确性及长输入提速门槛。修改算子后必须重新评测，旧结果会因哈希不同被拒绝。

## 实验边界

- 当前算子接收**相同采样率**的已解码 PCM；未研发新的重采样器。计时包含完整 PCM 有限值检查、声道准备及偏移估计，不包含解码、重采样、IPC、GPU 或界面。
- 测试数据包括已知整数延迟、增益、DC、噪声、一阶低通、前导静音、范围边界、整体反相和声道相消。真实录音来自本机四份 MP3 的前 30 秒，施加已知变换，不能替代独立采集录音的人工真值。
- 当前是整数固定延迟原型，不支持亚采样延迟、时钟漂移、动态时间规整或乐曲结构对齐。较强失真或频响改变可能被保守拒绝。
- 目前的实测采样率为 44.1/48 kHz；API 接受 8–192 kHz 不等于已经完整验证整个范围。
- 没有与产品界面集成，也没有在主工作区或 main 中修改功能、提交或合并。
